# Odum Soccer: Maximum Empower Football Simulation

## 1. About The Project

This application is a production-quality simulation game inspired by early Football Manager, designed to demonstrate Howard T. Odum’s Maximum Empower Principle applied to elite sport.

This is **not** a physics-based soccer simulator. It is a systems ecology simulator expressed through football.

## 3. Usage

*   **Start/Pause/Resume:** Control the simulation time.
*   **Speed Slider:** Adjust the simulation speed.
*   **Team Panels:** Monitor real-time emergy accounting for each team.

## 4. Understanding the Simulation

The simulation is based on Odum's principles, focusing on energy flows and transformations. Key concepts include:

*   **Power:** The rate at which energy is used.
*   **Transformity:** The quality of energy, representing the amount of energy of one type required to generate energy of another type.
*   **Empower:** The total energy flow, calculated as `Power × Transformity`.

The winning team is not necessarily the one with the most raw power, but the one that manages its emergy flows most effectively.

## 5. Key Features

*   **Hierarchical Energy Flows:** The game explicitly models energy flows at multiple scales, from the environment to the cellular level.
*   **Maximum Empower Principle:** The system is designed to maximize empower, not just power.
*   **Web Components:** The UI is built with vanilla Web Components, with no third-party libraries.
